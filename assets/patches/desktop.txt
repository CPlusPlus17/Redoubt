# STATUS: REVIEWED by LW-M1-01. Two kinds of entry live here.
#
# 1. DESKTOP-ONLY. Most entries touch only browser/, which browser/app.mozbuild:11
#    pulls in and mobile/android/app.mozbuild never does. Five further entries
#    were moved here from common.txt by LW-M1-01 because they were shown to be
#    compiled out or not traversed on Android - demonstrated from the tree, not
#    assumed from the filename (see docs/android/PATCH-SCOPE.md for the citation
#    behind each one). They are marked '# MOVED-FROM-COMMON' below.
#
#    Several of these describe behaviour Android still needs. They are desktop
#    *implementations*, not desktop *requirements*; the Android counterparts are
#    tracked as their own tasks, listed in PATCH-SCOPE.md.
#
# 2. DESKTOP HALVES of the former straddlers. NO STRADDLER IS PARKED HERE ANY
#    MORE - this section used to say "Seven entries edit both shared Gecko code
#    and browser/", and both halves of that sentence are now wrong: the count
#    was eight-minus-msix, not seven, and none of them is still a monolith.
#
#    LW-M1-01 nominated eight straddlers. Seven really did edit both shared
#    Gecko code and desktop-only code and were cut in half by LW-M1-02..04 and
#    LW-M1-06..09; the eighth, msix, was proved by LW-M1-05 never to have been
#    one. LW-M1-12 then deleted the seven monolithic files, regenerated the
#    assets/patches.txt shim and reconciled docs/android/PATCH-SCOPE.md. What
#    sits here now is seven <name>-desktop.patch entries, each in the position
#    its monolith had, with the matching <name>-common.patch in common.txt:
#
#      disable-data-reporting-desktop  LW-M1-02   + android/disable-data-reporting-android
#      eme-permission-desktop          LW-M1-03   no Android patch needed (checked)
#      moz-official-desktop            LW-M1-04   no Android patch needed (checked)
#      remove-pingsender-desktop       LW-M1-06   no Android patch needed (checked)
#      ui-patches/neterror-desktop     LW-M1-07   landmine L3 + android/neterror-jar
#      webgl-permission-desktop        LW-M1-08   landmine L1 + android/webgl-prompt-default
#      xmas-desktop                    LW-M1-09   keep LAST, see its entry below
#
#      msix                            LW-M1-05   NOT A STRADDLER - desktop-only, unsplit; see its entry below
#
#    (xmas used to be in no list at all - scripts/librewolf-patches.py applied
#    it from its own call site, after the whole list. LW-M1-09 removed that call
#    site and folded both halves in: xmas-common.patch in common.txt,
#    xmas-desktop.patch near the end of this file, which is where the old call
#    site put it in the sequence. pref-pane/pref-pane-small.patch was the last
#    one left in that position; LW-M1-13 folded it in too, as the final entry
#    below. NO PATCH IS APPLIED FROM ITS OWN CALL SITE ANY MORE - every patch
#    this repository applies is now an entry in one of these three lists, so
#    scripts/lint-patch-scope.py, scripts/check-patchfail.sh and --targets all
#    see the complete set.)
#
#    Android therefore gets the common half of all seven. That closes the parity
#    gap this section used to record - but not landmine L2: xmas-common puts lw/
#    into the Android build without getting librewolf.cfg into the APK, so there
#    is still no autoconfig/lockPref channel there. See the straddler table in
#    docs/android/PATCH-SCOPE.md for the per-patch evidence.
