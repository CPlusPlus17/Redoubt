Security & bug reports

Report privately

Security vulnerabilities, signature mismatches, a compromised download channel or a suspicious download: report them privately, in either of two ways. Please do not open a public issue for these.

  • By e-mail to security@redoubtbrowser.org. No GitHub account needed.
  • Through GitHub private vulnerability reporting.

The same contacts are in /.well-known/security.txt. The process is in SECURITY.md.

If an APK’s signing certificate does not show the SHA-256 digest below, or the F-Droid repository shows a different fingerprint from the one on the F-Droid page, do not install it, and include the sha256 of the file you have and where you got it in the report.

64:14:EB:33:46:81:CF:6E:92:90:34:B5:6A:06:2D:2B:8D:A0:90:82:21:72:F7:A3:95:2C:85:FD:D1:28:3B:D0

How fast security fixes ship

Redoubt follows Firefox’s regular release track. A release watch notifies the maintainer of every Firefox release and Mozilla security advisory. There is no guaranteed turnaround; the record so far:

  • Firefox 158.0 (2026-10-13) → Redoubt 158.0-1 the next day.
  • Firefox 157.0.1 (2026-10-06) → Redoubt 157.0.1-1 on 2026-10-10.

Only the latest release receives fixes. Keep Redoubt up to date with F-Droid, Obtainium or the in-app update check: Install & updates.

Who holds the signing key

One person, the maintainer, with no second key holder yet. Today the release key and the update-signing key are passphrase-encrypted files on the maintainer’s workstation, not on an offline machine; offline backups exist. Moving the keys to a hardware key (a YubiKey, with a touch for every signature) is planned. CI builds the APKs on another machine and never has a key. The release key is never uploaded to Google. Details: SIGNING.md.

Other bugs

  • Bugs in Gecko or Firefox for Android itself belong with Mozilla (Bugzilla); the issue form asks whether stock Firefox shows the same problem.
  • Everything else: open an issue using the Android bug form. Triage is described in TRIAGE.md.
  • Please do not report Redoubt problems to LibreWolf: they did not build it and cannot fix it.
