Passwords & passkeys

Redoubt works with your password manager through Android’s own autofill and Credential Manager. Passwords work with any manager. For passkeys, it depends on whether the manager trusts Redoubt as a browser.

Passwords

Choose your password manager (Bitwarden, KeePassDX, Proton Pass, Google Password Manager or another) as the autofill service in Android’s settings. Redoubt then offers its suggestions on normal login forms. Redoubt’s own password saving is off by default.

Login forms built inside page components (open shadow DOM, as on Reddit’s login page) reach your autofill service since Redoubt 158.0-1. This was tested with a test autofill service, not yet with Bitwarden, KeePassDX or Proton Pass. Fields inside closed shadow roots are still out of reach; for those, copy the username and password from your password manager.

Reddit’s login page itself currently stays blank in Redoubt, for a different reason: see Known issues.

Passkeys

Passkeys need Android 14 or later. Redoubt passes each passkey request to Android’s Credential Manager, along with the site’s address. Each password manager then decides whether it trusts Redoubt as a browser.

  • KeePassDX: works once you allow it. The first time Redoubt asks for a passkey, KeePassDX shows “App not recognized” and offers to add Redoubt to its privileged apps. You can also do this beforehand: Settings → Form filling → Passkeys settings → Privileged apps, then tick Redoubt.
  • Bitwarden: when you pick a passkey, Bitwarden says Redoubt is an “Unrecognized browser”. Choose Trust to add it to your own list of trusted apps. Redoubt is not on Bitwarden’s community list of browsers yet; we plan to ask Bitwarden to add it, so that this step will no longer be needed.
  • Proton Pass and Google Password Manager check browsers against fixed lists that do not include Redoubt yet. Neither lets you add a browser yourself, so they offer no passkeys to Redoubt until their makers add it.

We took the KeePassDX and Bitwarden steps from their source code. The project has not yet tested them with Redoubt on a phone.

Passkey suggestions in the username field

Some sites, Reddit among them, show passkeys as suggestions while you type in the username field (WebAuthn “conditional UI”). Firefox for Android does not support this at all: Gecko reports it as unavailable on Android, so Redoubt cannot offer it either. Use the site’s “Sign in with a passkey” button if it has one.
