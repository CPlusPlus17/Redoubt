This is a prepared checklist, not a record of execution. Use two dedicated, initialized English profiles/runs so disabled/private-denied and enabled/private-allowed preservation are checked independently. Keep the installed release APK hash, candidate source/patch manifest, device fingerprint, original XPI hashes, exact transferred-file hashes and transport configuration with each run. Signature enforcement must remain enabled. Use actual controls for every install/update/choice. The only privileged script supplied here observes state.

1. Run `fixtures.py` offline on the host. Put the exact two archived XPI files in a document-picker-visible directory on the dedicated device through root's normal file transfer. Verify the transferred bytes and retain those hashes. Use the original filenames so the picker selection can be bound to a known file. Record their document provider/URI when visible. Do not modify the manifest, extension ID/version, update URL, certificate or archive.
2. Prepare 1.73.0 through real Fenix controls. If packaged 1.74.0 is present, use its ordinary **Remove** control first. That source calls uninstall directly and returns to the manager after success; it has no second confirmation dialog. Preserve its existing preinstall/removal history. Do not reset the preinstall stamp, write profile metadata, invoke an install API or manufacture an older registry entry. If subsequent startup replaces 1.73.0 automatically, record that obstruction; do not classify the later version as a completed UI update.
3. Open Settings → About. Tap the actual app **wordmark five times** without leaving/resuming the About screen between taps. `AboutFragment` binds this trigger to `wordmark`; `SecretDebugMenuTrigger` resets its count on resume and enables the current-session menu on the fifth tap. Record the toast/revealed setting. The source view has `importantForAccessibility="no"`, so a `uiautomator` node for `wordmark` is not guaranteed; record actual screen/touch evidence if the control is absent from XML. Do not inject `showSecretDebugMenuThisSession` or any preference.
4. Return to Settings and choose **Install extension from file**, key `pref_key_install_local_addon`. The preference is normally hidden and becomes visible through the preceding real About trigger. A-C `AddonFilePicker` launches Android's `OpenDocument` contract accepting `application/x-xpinstall` and `application/zip`. Select the exact 1.73.0 XPI and follow the prompts that actually appear. The picker copies a provider URI to a temporary file and calls the ordinary `InstallationMethod.FROM_FILE` engine route. It does not bypass Gecko signature validation.
5. Observe the installed ID/version and ordinary `AddonManager.SIGNEDSTATE_SIGNED` result using the read-only `observe-installed.js` body. Require `geckoNewerThanOlder > 0`, `signatureEnforcement === true`, `isBuiltin === false`, exact ID and version 1.73.0. Record the actual numeric signed state and comparator value. A ZIP `META-INF` entry, no visible error, or AMO's metadata is insufficient. Restart once during setup and re-observe the actual older version; a preexisting newer version or silent replacement invalidates the starting condition.
6. Establish the run's state with real add-on controls (`enable_switch`, `allow_in_private_browsing_switch`). For disabled/private-denied, deny private access while enabled, then disable. For enabled/private-allowed, enable and grant private access. Keep UI evidence after the asynchronous completion controls are interactive, alongside registry, live policy/listeners and independent persisted state. Do not rely on the optimistic checked bit. Run the parser controls for the old version before selecting the new file; require page callbacks plus independent allowed/blocked server request evidence. The prepared rule exists in both originals.
7. Repeat the real About trigger if needed after restart, open **Install extension from file** and select the exact 1.74.0 file while 1.73.0 remains installed. Do **not** remove the older version between these selections: the measured operation must update the same ID. Follow and record actual prompts. No extra prompt is invented when Gecko offers none. `AddonFilePicker` success only logs completion and removes its temporary copy; it does not supply a unique success dialog. Picker dismissal alone cannot establish success. Require the actual installed-details version change and completed interactive controls, plus the read-only exact registry/version/signed-state transition and matching disk/cache version.
8. Confirm all choices survived: disabled/private-denied remains disabled and denied; enabled/private-allowed remains enabled and allowed. Do not click a choice afterward to repair it. Record the actual active policy/listener state, JSON/database/cache versions and private permission in addition to the registry row. Update failure, unchanged version, reset permission, live listener mismatch or the wrong source artifact is a failure/pending checkpoint, never a pass.
9. Force-stop and restart after the observed update completion, retaining both the actual UI evidence and measured completion-to-stop timing. UI dump idle waits may prevent a sub-second durability claim: keep that particular timing checkpoint unproven when the interval cannot be established. Do not label a later successful startup an immediate native regression. The independent API durability regressions remain separate; this checklist does not call privileged install/update methods.
10. On the first intended normal fixture navigation after restart, require parser document/report completion before observer attachment, exact new run/case/document/origin binding and actual independent server requests. Then create a new real private context and test its first fixture document; retain whether private was first in that context or first in the process instead of conflating them. For enabled/private-allowed, the matching parser resource must be blocked in both modes and the allowed control must execute. For disabled/private-denied, both resources must execute in both modes. Confirm 1.74.0 and the retained choices again without repairs. Close private tabs through the actual UI and record teardown.
