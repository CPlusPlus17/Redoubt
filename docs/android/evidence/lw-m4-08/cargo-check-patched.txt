# central question open: a Rust patch that does not compile is worth nothing,
# and neither `patch --dry-run` nor any of the scope/order gates can tell you.
#
# Method: apply the patch to the extracted tree, run cargo check inside the
# build container (which is where the vendored crate sources resolve), revert.
# The container is required: obj-x86_64/.cargo/config.toml maps every git
# dependency to `vendored-sources`, whose `directory` is the CONTAINER path
# /work/src/third_party/rust. Running cargo from the host, or from /work/src
# rather than /work/src/obj-x86_64, fails on `allocator-api2` in offline mode —
# cargo discovers config by walking up from the cwd, and the config lives in
# the objdir, not the srcdir.
#
#   podman run --rm -v <tree>:/work/src:z -w /work/src/obj-x86_64 \
#     localhost/librewolf-android-build:latest \
#     bash -lc 'cargo check -p remote_settings --offline \
#                 --manifest-path /work/src/Cargo.toml --message-format=short'
#
# RESULT: compiles. 10 warnings, 0 errors, "Finished dev profile in 42.85s".
#
# The warnings are all dead-code/unused-import fallout from removing the network
# bodies, and they CANNOT break this build: build/moz.configure/rust.configure:797
# adds -Dwarnings only under --enable-warnings-as-errors, which assets/mozconfig
# .android does not set. The objdir proves it rather than the source implying it:
#   obj-x86_64/config.status:645
#   'MOZ_RUST_DEFAULT_FLAGS': ['-C', 'debuginfo=2', '--cap-lints', 'warn']
# --cap-lints warn caps every lint at warning level for the whole graph.
